# Tools brand assets

| Asset | Background | Intended use |
| --- | --- | --- |
| `logo-light.svg` | Transparent | Wordmark on a light surface |
| `logo-dark.svg` | Transparent | Wordmark on a dark surface |
| `logo-light-background.svg` | Included light panel | Portable light presentation |
| `logo-dark-background.svg` | Included dark panel | Portable dark presentation |
| `banner-light.svg` | Included | README and social header on light themes |
| `banner-dark.svg` | Included | README and social header on dark themes |

The mark is a governed core wired to four connector ports; each wire passes through a gate.
It pairs with the Runtime's execution-graph mark: the Runtime runs agents, Tools connect them to
the systems they act on, and every connection is governed. Keep the logo aspect ratio and the
accessible title and description; do not remove the gates or recolor individual ports.

Colors follow the Algen palette used by `algen.ai`, Agent Runtime and Agent Studio: gold
gradients (`#F3D98B` → `#D4A017` → `#B8860B`), warm charcoal (`#0C0C0B` → `#2A2418`), ivory
surfaces (`#FDFCF9` → `#F4EFE3`), and accessible ink or ivory text for the selected background.
